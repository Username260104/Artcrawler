# 전체 로드맵

## 1. 제품 방향

이 제품은 한국 동시대 미술 전시를 확인하기 위한 신뢰 가능한 달력에서 시작한다.

장기적으로는 전시 발견, 기관/갤러리별 프로그램 추적, 작가별 전시 이력, 아트페어 기간 특화 탐색, 개인 알림까지 확장할 수 있다. 하지만 첫 버전은 전시 날짜 확인 문제만 해결한다.

장기 가치:

- 많은 전시를 모으는 것보다 중요한 전시를 안정적으로 모은다.
- 공식 출처 기반으로 신뢰도를 확보한다.
- 동시대 미술 씬의 권위와 맥락을 반영한다.
- 시간이 쌓일수록 전시 아카이브 자체가 자산이 된다.

## 2. 설계 원칙

- 달력 우선, 포털 후순위
- 공식 출처 우선
- 양보다 권위와 신뢰도 우선
- 사용자 접속 시 크롤링 금지
- 백그라운드 예약 수집
- 기관별 adapter 구조
- 수집 대상 목록과 활성 크롤러 분리
- 사용자 화면에는 안정적인 데이터만 노출
- 크롤링 이력과 실패 원인을 남긴다

## 3. 권위 기준

기관/갤러리 포함 여부는 방문객 수나 대중적 인지도만으로 정하지 않는다. 동시대 미술 씬에서의 권위와 프로그램의 질을 기준으로 한다.

권위 판단 요소:

- 한국 동시대 미술 담론에서의 영향력
- 국제 동시대 미술 시장 및 전시 맥락과의 연결성
- 주요 작가 전시 이력
- 큐레이토리얼 프로그램의 지속성
- Frieze Seoul, Kiaf, 서울아트위크 등 주요 장면과의 연결
- 미술관, 비평, 컬렉터, 갤러리 씬에서의 반복적 참조
- 공식 전시 아카이브 관리 여부

## 4. 기관 티어

### Tier A: 핵심 권위 기관/갤러리

한국 및 국제 동시대 미술 맥락에서 지속적 영향력을 가진 기관과 갤러리.

예시:

- 국립현대미술관 서울
- 서울시립미술관
- 리움미술관
- 아트선재센터
- 송은
- 국제갤러리
- 갤러리현대
- PKM 갤러리
- Pace Seoul
- Perrotin Seoul
- Lehmann Maupin Seoul
- White Cube Seoul
- Thaddaeus Ropac Seoul

### Tier B: 강한 서울 동시대 미술 프로그램

씬 안에서 충분한 영향력이 있고 정기적인 프로그램을 가진 공간.

예시:

- 아라리오갤러리
- 갤러리바톤
- 바라캇 컨템포러리
- P21
- 휘슬
- 갤러리2
- 제이슨함
- BB&M
- Gladstone Seoul
- Esther Schipper Seoul
- 아모레퍼시픽미술관
- 일민미술관

### Tier C: 실험적/신진 씬

작가 운영 공간, 프로젝트 스페이스, 실험적 비영리 공간.

중요할 수 있지만 공지 방식이 불규칙할 가능성이 높다. 핵심 크롤러 구조가 안정화된 뒤 추가한다.

### Tier D: 기간 한정 이벤트

Frieze Seoul, Kiaf, 서울아트위크, 비엔날레, 팝업, 페어 기간 오프사이트 전시.

상시 기관 데이터와 섞기보다 시즌성 overlay로 다루는 것이 좋다.

## 5. 버전 개요

```text
V0: 달력 MVP
V1: 자동 수집 안정화
V2: 전시 발견과 방문 계획
V3: 씬 맥락 기반 지능화
V4: 개인화와 리서치 기능
```

## 6. V0: 달력 MVP

목표:

사용자가 달력에서 전시 기간을 확인한다.

핵심 기능:

- 월간 달력
- 날짜별 전시 목록
- 미술관/갤러리 필터
- 전시 상세
- 공식 출처 링크
- 하루 1회 예약 크롤링
- 크롤링 로그

대상 범위:

- 활성 자동 수집 기관 6-10곳
- 등록된 후보 기관 15-20곳

완료 기준:

- 사용자가 오늘 볼 수 있는 전시를 즉시 확인할 수 있다.
- 웹은 DB만 읽기 때문에 빠르게 열린다.
- 최소 6곳의 권위 기관/갤러리가 안정적으로 갱신된다.
- 크롤링 실패가 사용자 화면을 깨뜨리지 않는다.

## 7. V1: 자동 수집 안정화

목표:

기관 수를 늘려도 데이터 품질이 무너지지 않도록 수집 시스템을 강화한다.

기능:

- adapter별 fixture 테스트
- 날짜 파싱 테스트
- 원문 HTML/JSON snapshot 저장
- 크롤링 상태 확인 화면
- 중복 감지
- 변경 감지
- 기관별 마지막 확인 시각
- 낮은 신뢰도 데이터 보류

대상 범위:

- 활성 자동 수집 기관 15-25곳

이 단계에서 구분해야 할 상태:

- 공식 출처에서 확인된 전시
- 날짜나 제목이 변경된 전시
- 공식 출처에서 사라진 전시
- 파싱 실패
- 낮은 신뢰도 후보

완료 기준:

- 새 기관 추가가 대부분 adapter 추가 작업으로 제한된다.
- 고장 난 adapter를 빠르게 찾을 수 있다.
- 크롤러 품질이 들쭉날쭉해도 공개 달력은 안정적으로 유지된다.

## 8. V2: 전시 발견과 방문 계획

목표:

단순 확인을 넘어 실제 관람 계획에 도움이 되게 만든다.

기능:

- 주간 보기
- agenda/list 보기
- 종료 임박 전시 페이지
- 곧 시작하는 전시 페이지
- 기관별 페이지
- 지역 필터
- 작가 검색
- 전시 이미지
- 오프닝 리셉션 정보
- 기본 지도 보기

지역 구분 예시:

- 삼청/종로
- 한남/이태원
- 청담/압구정
- 용산
- 성수
- 마포/홍대

완료 기준:

- 사용자가 주말 관람 동선을 짤 수 있다.
- 7일 이내 종료 전시를 빠르게 찾을 수 있다.
- 기관별 페이지가 단순 기록이 아니라 탐색 입구가 된다.

## 9. V3: 씬 맥락 기반 지능화

목표:

날짜 데이터에 동시대 미술 씬의 맥락을 얹는다.

기능:

- 권위 가중 정렬
- 작가 프로필 연결
- 기관/갤러리/작가 관계 그래프
- Frieze/Kiaf 기간 특화 모드
- 비엔날레 및 아트페어 overlay
- 이번 주 주요 전시 보기
- 공식 보도자료 기반 짧은 요약
- 전시 변경 알림

주의:

이 단계가 일반적인 AI 미술 감상평 생성기로 변하면 안 된다. 목표는 사용자가 무엇을 볼지 판단하는 데 필요한 맥락을 주는 것이다. 출처, 불확실성, 공식 링크가 계속 중심이어야 한다.

완료 기준:

- 최신순만으로는 보이지 않는 중요한 전시를 드러낼 수 있다.
- 기관전, 블루칩 갤러리 전시, 신진 공간 프로그램을 구분해 보여줄 수 있다.
- 페어 기간의 과밀한 전시 정보를 다룰 수 있다.

## 10. V4: 개인화와 리서치 기능

목표:

정기 관람자, 컬렉터, 큐레이터, 필자, 리서처가 쓸 수 있는 도구로 확장한다.

기능:

- 사용자 계정
- 저장한 전시
- 개인 캘린더 내보내기
- 이메일/푸시 알림
- 작가/기관 follow
- 리서치 노트
- 전시 아카이브 검색
- CSV export
- API 제공
- 과거 전시 데이터셋

고급 기능:

- 작가별 전시 이력
- 기관별 프로그램 패턴
- 국문/영문 전시명 매칭
- 여러 출처 간 데이터 reconciliation
- 비평/언론 언급 추적

완료 기준:

- 단기 관람 계획을 넘어 장기 리서치에 쓸 수 있다.
- 축적된 전시 데이터가 독립적인 자산이 된다.
- 고급 사용자가 자신의 워크플로에 연결할 수 있다.

## 11. 데이터 확장 전략

확장은 한 번에 하지 않고 층으로 나눈다.

### Layer 1: 구조가 안정적인 공식 사이트

공식 전시 페이지가 명확하고 파싱 난이도가 낮은 곳부터 시작한다.

예시:

- Pace
- White Cube
- Perrotin
- Lehmann Maupin
- Thaddaeus Ropac
- Gladstone
- Esther Schipper

### Layer 2: 국내 주요 갤러리

권위가 높고 공식 사이트 구조가 비교적 안정적인 국내 갤러리를 추가한다.

예시:

- 국제갤러리
- 갤러리현대
- PKM 갤러리
- 아라리오갤러리
- 갤러리바톤
- 바라캇 컨템포러리
- P21

### Layer 3: 미술관/기관

기관은 지점, 프로그램 유형, 국문/영문 페이지, 예약 정보가 섞일 수 있으므로 별도 정규화가 필요하다.

예시:

- 국립현대미술관
- 서울시립미술관
- 리움미술관
- 아트선재센터
- 송은
- 아모레퍼시픽미술관
- 일민미술관

### Layer 4: 실험적 공간

공지 구조가 불규칙한 공간은 후순위로 둔다.

필요할 수 있는 기술:

- PDF 파싱
- 이미지 OCR
- 인스타그램 보조 모니터링
- 더 보수적인 confidence scoring

### Layer 5: 이벤트 overlay

기간 한정 이벤트는 상시 전시 데이터와 별도로 관리한다.

예시:

- Frieze Seoul
- Kiaf
- 서울아트위크
- 비엔날레
- 갤러리 위크엔드 프로그램

## 12. 운영 로드맵

### 초기 운영

- 하루 1회 크롤링
- DB에 에러 로그 저장
- 반복 실패 확인
- 실패한 adapter는 개발 이슈로 처리

### 성숙 단계 운영

- 크롤링 건강 상태 대시보드
- Tier A 기관 반복 실패 알림
- 이전 수집 결과와 현재 결과 비교
- 원문 snapshot 보관
- parser가 깨질 때 fixture 테스트 추가

### 이후 운영

- 기관별 데이터 품질 점수
- 출처 구조 변경 자동 감지
- 별도 crawler worker
- queue 기반 크롤링
- 도메인별 rate limit
- 재시도 정책

## 13. UX 로드맵

### V0 UX

### V1 UX

필터 정리, 기관 페이지, 빈 상태 개선, 모바일 가독성 개선.

### V4 UX

저장, follow, export, 알림, 노트 등 개인 워크플로.

## 15. 주요 제품 결정

### 결정 1: 타임라인보다 달력 먼저

처음 문제는 전시 기간 확인이다. 복잡한 가로 타임라인보다 달력이 더 직접적이다.

### 결정 2: 공식 출처 우선

써드파티 전시 모음 사이트는 참고 자료로 쓸 수 있지만, canonical record는 공식 페이지에서 만든다.

### 결정 3: 기관별 adapter 방식

갤러리 사이트는 구조가 너무 다르다. 하나의 만능 scraper보다 기관별 adapter가 정확하고 고장 위치도 찾기 쉽다.

### 결정 4: 넓은 후보 목록, 좁은 활성화

권위 있는 기관 목록은 넓게 유지하되, 공개 데이터는 안정적인 crawler가 있는 기관만 노출한다.

### 결정 5: 추천은 나중에

처음부터 주관적 추천을 하지 않는다. 먼저 날짜와 출처의 신뢰도를 확보한다. 이후 권위와 맥락을 반영한 발견 기능을 추가한다.

## 16. 장기 목표

최종적으로 제품이 답해야 할 질문:

- 지금 서울에서 볼 수 있는 중요한 동시대 미술 전시는 무엇인가?
- 곧 시작하는 전시는 무엇인가?
- 곧 끝나는 전시는 무엇인가?
- 현재 씬에서 주목할 만한 전시는 무엇인가?
- 특정 작가나 기관은 시간에 따라 어떤 전시 이력을 만들어 왔는가?

첫 버전은 앞의 세 질문만 잘 답하면 된다.
